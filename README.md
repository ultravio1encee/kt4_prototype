# КТ-4 — проверка ZIP-архива по контрольному JSON

Рабочий учебный прототип на Python и Streamlit. Пользователь загружает ZIP и контрольный JSON, запускает проверку и получает таблицу результатов и CSV-отчёт.

## Требования

- Python 3.10 или новее;
- доступ к установке пакетов Python.

## Запуск в PyCharm

1. Распакуйте папку проекта и откройте её в PyCharm через **File → Open**.
2. Убедитесь, что для проекта выбран Python 3.10 или новее.
3. Откройте вкладку Terminal внизу PyCharm.
4. Выполните команду:

   ```bash
   python -m pip install -r requirements.txt
   ```

5. Запустите приложение командой:

   ```bash
   python -m streamlit run app.py
   ```

6. В браузере откроется локальная страница Streamlit. Загрузите ZIP и JSON, затем нажмите **Проверить**.

Чтобы остановить приложение, вернитесь в Terminal и нажмите **Ctrl+C**.

## Проверка четырёх сценариев

В папке проекта есть `tests/test_checker.py`. Он автоматически создаёт временные ZIP в памяти и проверяет четыре статуса, а также ошибки JSON и ZIP.

Запуск тестов из Terminal:

```bash
python -m unittest discover -s tests -v
```
